# ゆうしゃ、はじめました。

ドット絵のクラシックターン制RPG(ブラウザ / GitHub Pages)。コミカルな一人旅の勇者となって、5つの章を巡り魔王を討伐する王道ファンタジー。

## 特徴
- クラシックターン制コマンドバトル(たたかう/とくぎ/どうぐ/にげる、属性相性、クリティカル・回避)
- ワールドマップを自由に行き来できる5章構成 + クリア後の隠しダンジョン・裏ボス
- 装備・アイテム・スキル・モンスター図鑑
- 経験値レベルアップ、ショップ、宿屋、ランダムエンカウント
- 自動セーブ(localStorage)、ゲームオーバー時はペナルティなしで直前地点から再開
- クリアタイムの世界ランキング(Supabase)
- Web Audio APIによる合成BGM・効果音
- スマホ縦持ち対応レスポンシブ

## 遊び方
方向キー(スマホは十字ボタン)で移動、○ボタンで決定・話しかける、✕ボタンでキャンセル。町や洞窟を歩き回り、魔物を倒してレベルを上げながら魔王城を目指そう。

## 技術構成
- Vanilla JS + Canvas 2D(ビルド不要、外部アセット無しでドット絵を全てコードから生成)
- `js/pixelart.js` ドット絵スプライト定義・描画
- `js/mapgen.js` マップ用グリッド構築ヘルパー
- `js/data.js` モンスター・装備・アイテム・マップ・ストーリーなどのゲームデータ
- `js/player.js` プレイヤーの状態操作(レベル・装備・所持品)
- `js/battle.js` ターン制バトルのロジックと描画
- `js/world.js` フィールド(ワールドマップ・町・ダンジョン)の歩行・イベント
- `js/ui.js` ウィンドウ・テキストボックス・メニューのUI部品
- `js/audio.js` Web Audio APIによるBGM・効果音合成
- `js/save.js` localStorageへのセーブ/ロード・周回引き継ぎ
- `js/ranking.js` Supabaseへのクリアタイムランキング送信・取得
- `js/main.js` ゲーム全体のステートマシン・入力処理
